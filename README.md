## 实测稳定性到底如何

根据多个第三方测评的反馈，AkkoCloud的CN2 GIA线路丢包率几乎为零。圣何塞机房ping值在150-170ms之间，非高峰时段文件下载速度实测能到6MB/s左右。有用户反馈，晚上10点黄金时段欧洲线路依然能跑到60Mbps，这在欧洲VPS里属于顶级水平。德国法兰克福ping值约180ms，比很多动辄230ms+的普通海外VPS好上一大截。

晚高峰会有速度回落，但不会完全不可用，这已经比那些晚高峰直接"消失"的普通线路强太多了。售后方面提供工单和QQ渠道，目前主要支持支付宝付款，部分套餐也支持PayPal。
